## Overview

JPEG (`.jpg` / `.jpeg`) is the most widely supported image format for photography and photorealistic content. Stockflow.media JPEG assets are available in resolutions up to **8K (7680×4320)** — making them ideal for both digital and large-format print use.

---

## Common Use Cases

### Print Design
JPEG files at 8K resolution print sharply at:

| Print Size | Min Resolution Required | Stockflow 8K Result |
|---|---|---|
| A4 (210×297mm) | 2480×3508px at 300 DPI | Excellent |
| A1 (594×841mm) | 7016×9933px at 300 DPI | Sharp |
| A0 Poster | 9933×14043px at 300 DPI | Good at 200 DPI |
| Exhibition Banner | 3000px+ wide | Excellent |

Ideal for:
- Science posters and research display boards
- Museum exhibition prints and wall art
- Restaurant menus and food photography inserts
- Classroom wall charts and biology reference charts

### Digital Publishing and Web Backgrounds
- Website hero section backgrounds
- Blog article featured images
- Email newsletter headers
- Digital magazine spreads
- Ebook cover art and interior illustrations

### Design and Presentation Work
- Slide deck backgrounds in PowerPoint, Keynote, Google Slides
- Canva project background layers
- InDesign and QuarkXPress editorial layouts
- Adobe Photoshop composition base layers

### Social Media
- Instagram feed posts (square crop from 1:1 assets)
- LinkedIn article header images
- Pinterest pins (vertical crop from 9:16 assets)
- Facebook cover photos

---

## How to Use JPEG in Editing Tools

| Software | How to Import |
|---|---|
| Photoshop | File > Open or drag into canvas |
| Canva | Uploads > Upload files |
| PowerPoint | Insert > Pictures > This Device |
| InDesign | File > Place |
| Premiere Pro | Import, use as still frame or background |

> **Tip:** For web use, convert JPEG to WebP using Squoosh or Photoshop's Save for Web to reduce file size by ~30% while maintaining quality.

---

## JPEG Format Details

| Property | Value |
|---|---|
| Extension | `.jpg` / `.jpeg` |
| Colour Mode | RGB (full colour) |
| Transparency | Not supported |
| Max Stockflow Resolution | 8K (7680×4320) |
| Aspect Ratios Available | 16:9, 9:16, 1:1 |
| Best For | Print, photography, backgrounds |
