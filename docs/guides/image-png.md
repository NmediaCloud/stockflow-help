## Overview

PNG (Portable Network Graphics) is the standard format for images requiring **transparency**, precision, and lossless quality. PNG versions are available for select collections — ideal for layering, compositing, and design work.

## Why PNG for Creative Projects?

Unlike JPEG, PNG supports a **transparent background (alpha channel)** — meaning you can place the image over any colour, texture, or video without a white or coloured box around it.

This makes PNG the professional standard for:
- **Logo design** — no background, scalable overlay on brand materials
- **Web UI elements** — buttons, icons, overlays, illustrations
- **Compositing** — layering imagery over video or presentation slides
- **Broadcast graphics** — lower thirds, title cards, motion graphics

## Common Use Cases

### Logo and Artwork
- Scientific organism illustrations placed over branded backgrounds
- Transparent microscopic cell overlays for biotech company branding
- Poster artwork where the subject floats freely on the canvas

### Web Design
- Website UI overlays — transparent image elements on coloured sections
- CSS background-image layers on web pages
- Icon sets from biological or food imagery
- Favicon and app icon source files

### Video Motion Graphics
- Import PNG sequences into After Effects, Premiere Pro, or DaVinci Resolve as transparent overlays
- Animate PNG elements across video backgrounds
- Use as lower-third graphics or topic illustration cards in YouTube videos

### Print with Cutouts
- Product packaging where the image appears without a rectangular boundary
- Sticker printing with die-cut transparent edges
- Science textbook illustrations with subject-only cutouts

## PNG vs JPEG — When to Use Which

| Use Case | JPEG | PNG |
|---|---|---|
| Photo-realistic backgrounds | Best choice | Larger file size |
| Transparent backgrounds | Not supported | Required |
| Web use (solid background) | Fast, efficient | Works well |
| Logo overlays | Not supported | Required |
| Print at large scale | 8K excellent | Lossless quality |

## PNG Format Details

| Property | Value |
|---|---|
| Extension | `.png` |
| Colour Mode | RGB + Alpha (RGBA) |
| Transparency | Full support |
| Compression | Lossless |
| Best For | Logos, overlays, UI, compositing |
