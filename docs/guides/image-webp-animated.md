## Overview

**Animated WebP** is a modern image format that provides GIF-like animation with significantly better quality and smaller file sizes — the next generation of animated images for web and digital use.

> **Coming soon:** Stockflow.media will be adding animated WebP assets — including looping microscopic animations, food motion clips, and UI-ready science loops.

---

## What Is Animated WebP?

Animated WebP files work like GIFs but with substantial improvements:

| Feature | GIF | Animated WebP |
|---|---|---|
| Max colours | 256 | 16.7 million (full colour) |
| Transparency | Basic (1-bit) | Full alpha channel |
| File size | Large | Up to 64% smaller |
| Loop support | Yes | Yes |
| Browser support | Universal | All modern browsers |
| Best for | Simple animations | Rich, smooth animations |

## Use Cases

### Web Animations and UI
- Website hero section loops — a microscopic cell or food scene playing silently as a background
- Loading animations with science-themed visuals for biotech or education websites
- Hover effects that trigger on mouse interaction

### Social Media and Messaging
- WhatsApp sticker packs (supports animated WebP natively)
- Telegram animated stickers
- Discord animated emoji and server expressions
- Tumblr and Reddit animated post content

### Educational Interactives
- Embed animated WebP in e-learning modules (Articulate, Rise)
- Use in interactive textbooks to show biological processes looping
- Digital classroom displays with animated biology content

### Email Marketing
- Animated WebP works in many email clients (Gmail, Apple Mail)
- Promotional emails with subtle animated product visuals

### Canva and Design Tools
- Canva supports animated WebP as uploaded animated elements
- Create animated social media carousels with subtle motion
