# How to Use Vector Files from Stockflow.media

Stockflow.media's vector assets are ideal for designers, agencies, and developers who need infinitely scalable, lossless graphics. They can be resized to any dimension — from a small mobile icon to a full billboard print — without any quality loss.

---

## Supported Vector Formats

| Format | Description | Best For |
|--------|-------------|----------|
| **SVG** | Web-native, editable XML format | Web design, UI/UX, interactive animations |
| **EPS** | Professional vector format | Print design, magazine layouts, branding |
| **AI**  | Adobe Illustrator native | Complex multi-layer design work |
| **PDF** | Universal print-ready format | High-fidelity print and press production |

---

## Opening Vector Files

### Adobe Illustrator
1. Go to **File > Open** and select your vector file.
2. Each element (shapes, lines, fills) is fully editable.
3. Use **Object > Expand** to separate complex grouped elements.

### Figma
1. Drag and drop the **SVG** directly onto your canvas.
2. All vector paths are automatically editable.
3. Resize using the **constraint handles** without quality loss.

### Inkscape (Free & Open Source)
1. Use **File > Open** for SVG or EPS files.
2. Use **Object Properties** to explore layer structure.

### For Print (InDesign / Affinity Publisher)
1. **Place** (`Ctrl+D`) the EPS or PDF into your layout.
2. Scale freely — vector quality is resolution-independent at any print size.

---

## Tips for Best Results

- Always use **SVG** for web and screen; use **EPS or PDF** for professional print.
- If exporting from Illustrator for the web, use **Save As > SVG** and enable "Embed Images" only if needed.
- Vectors from our **Microscopic** and **Food & Beverage** collections work exceptionally well as stylised background elements or icon overlays.
