# How to Use MP4 Video Footage from Stockflow.media

Stockflow.media's MP4 video assets are professionally produced in resolutions up to **4K and 8K**, making them ready for any production pipeline — from quick social media posts to full-length documentary films.

| **16:9 Widescreen** | Up to 3840×2160 | YouTube, TV, documentaries |
| **9:16 Vertical**  | Up to 2160×3840 | Instagram Reels, TikTok, Shorts |

## Using MP4 Footage in Video Editors

### Adobe Premiere Pro
1. Import the `.mp4` file via **File > Import**.
2. Drag the clip to your sequence timeline.
3. Use **Effect Controls** to scale, mask, or colour grade.

### DaVinci Resolve
1. In the **Media Pool**, right-click and choose **Import Media**.
2. Match your timeline resolution to the footage resolution for best results.
3. Use the **Color** page for professional grade correction.

### Final Cut Pro
1. Import using **File > Import > Media**.
2. Enable **Optimised Media** for smoother playback on large files.

## Tips for Best Results

- **Do not re-compress** unnecessarily. Export at the same codec and bitrate when possible.
- For **documentary overlays**, use the 16:9 widescreen versions as B-roll on a lower opacity layer.
- For **social content**, use the vertical 9:16 versions — they are pre-framed for mobile screens.
- All clips are **royalty-free** once licensed. No attribution required.
